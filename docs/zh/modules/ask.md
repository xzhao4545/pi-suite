# Ask

[文档索引](../index.md)

`ask_user` 让模型在替换编辑器的面板中向你提出单个问题或 2–4 个批量问题。开关：`modules.ask`。

在主会话中，该工具需要 Pi 的交互终端（TUI），print 或 RPC 模式下会失败。子代理的 `ask_user` 问题交给它的直接父级，而不是你，见 [Agents](agents/index.md)。

## 参数

| 参数 | 含义 |
| --- | --- |
| `question` | 单题时为问题；使用 `questions` 时为整批的标题。 |
| `questions` | 2–4 项，每项有自己的 `question`、`options`、默认值，以及可选的 `title`（1–60 个字符，用作页签标题）。 |
| `options` | 字符串，或对象 `{ id?, title, description?, recommended? }`。ID 默认为 `option-1`、`option-2` 等。 |
| `allowMultiple` | 多选，默认 `false`。 |
| `defaultAnswer` | 预填的自定义文字。 |
| `defaultOptionId` / `defaultOptionIds` | 单选的预选项，或多选的预选项列表。 |
| `allowComment` | 显示可选的评论输入框。 |
| `timeoutMs` | 空闲超时，单位毫秒。省略时使用 `ask.timeout`（默认 10 分钟）；`0` 关闭超时。 |

批量提问时，`options`、默认值和 `allowMultiple` 写在 `questions` 的各项内部。

每个问题都可以输入文字回答：列表末尾始终有一个带 ✎ 的自定义项。单选时，自定义回答替代所选选项；多选时，它与已勾选的选项一并提交。`recommended` 选项会突出显示，但从不预选。默认值不匹配或选项 ID 未知时，在面板出现前就会报错。

## 超时

计时器衡量的是空闲时间。面板首次出现时开始计时，任何按键、粘贴、被处理的点击或滚轮都会让它重新开始。排在其他问题后面等待的时间不计入。剩余时间显示为 `idle mm:ss`。

到期后面板自动提交：有当前选择或预填答案时使用它；否则选择第一个推荐选项（多选时选择全部推荐选项），没有推荐时选择第一个选项。未选中的草稿文字不会被使用。没有选项也没有草稿的自由文字问题保持未回答。以这种方式提交的每个答案（包括你的当前选择）都标记为 `autoSelected: true`。

## 结果状态

| 状态 | 发生了什么 | 影响 |
| --- | --- | --- |
| `answered` | 你提交了答案。 | 模型和目标继续。 |
| `skipped` | 在问题列表上按 Esc，或执行 Skip 操作。返回已有的选择和草稿，未回答的问题保持未回答。 | 模型继续。这不代表同意。 |
| `timed_out` | 空闲计时到期，面板按 [超时](#超时) 所述自动提交。 | 模型按这些答案继续。这不代表同意。 |
| `cancelled` | 请求被中止、会话切换或 Pi 重新加载。 | 本轮结束。活动目标暂停，直到你发送下一条消息或执行 `/goal resume`。 |

工具结果文本以状态开头，逐题列出所选答案。`skipped` 和 `timed_out` 的结果会注明 `not consent`，因此跳过或超时的答案不能用来授权破坏性操作。

## 按键

| 按键 | 操作 |
| --- | --- |
| ↑ / ↓ | 在选项之间移动。 |
| 空格 | 选择或切换勾选。 |
| Enter | 单选：选中并确认。多选：确认已勾选的集合。在自定义项上：开始或结束输入。 |
| `f` | 输入自定义回答。 |
| `/` | 搜索选项。 |
| ← / → | 在批量问题之间切换，最后一个页签是 Review。 |
| Tab | 移到操作栏。 |
| `e` | 展开或收起较长的问题和选项。 |
| `d` | 查看问题和选项的全文。 |
| Ctrl+H（`ask.historyKey`） | 在问题上方显示对话历史，草稿保留。 |
| Esc | 返回上一级；在问题列表上则跳过整个提问。 |

批量问题在全部回答后从 Review 页提交。跳过后焦点回到 Pi 的编辑器，模型继续运行；此时再按 Esc 是 Pi 的正常中断。

面板高度不超过终端的 70%，在小终端中缩为紧凑形式。鼠标点击可选择页签和选项，滚轮移动选择。

## 来自子代理的问题

子代理调用 `ask_user` 时，问题交给它的直接父级，而不是用户，见 [Agents](agents/index.md#父级提问)。
