目标：以上游任务存储与会话机制为基础，接入两级结构、原子批量编辑、共享显示与执行引用。

## 完成项

- [x] 父子共用稳定短 ID，父级进度和状态派生，增删、移动、重新打开同步重算；不接受第三层。
- [x] task_list 与 task_edit 精简查询/修改结果，整批校验和原子提交；保留依赖与反向关系、阻塞警告及删除清理。

- [x] 真实 SDK 的 new/resume/fork/reload 清单独立与继承，未持久化会话只保留内存清单。
