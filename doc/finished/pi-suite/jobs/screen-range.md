# PTY 线性输出与屏幕支持范围

Linux、Pi 1.5.0、Node.js 24 的真实 JobManager PTY 验证明确了 [输出待办](../../../todo/pi-suite/index.md) 的垂直/全屏支持范围；该阶段只核对已有 reader、xterm 与屏幕查看入口。

- 垂直重写后 xterm 显示 `NEW_A / OLD_B`，线性 reader 显示 `OLD_A / NEW_A`。reader 在当前读取片段内处理单物理行的横向覆写，跨行定位不会回写此前的线性行。
- 备用屏幕清屏并重绘两帧后，xterm 只显示当前帧；线性日志片段仍包含旧帧，可能与新帧拼接。读取、搜索与结算预览均不保证最终二维画面；原始字节偏移与实际日志长度一致。
- 同 owner 运行时结束/停止后仍可查看释放时保留的当前 viewport 与退出提示。停在备用屏幕时保留该屏幕；结束前返回主屏时保留主屏。Pi 重启后能读取带 fullScreen 标志的历史记录，但没有终端屏幕句柄。
- 现有 SerializeAddon 可直接用于 headless，并按相同尺寸恢复当前备用屏幕；序列化不包含被覆盖的旧帧。上游同样只读取当前缓冲区，不能据此承诺完整历史还原。

屏幕查看复用现有 xterm 与 /jobs；该验收不代表二维历史重放已实现，也不覆盖 Windows 或真实手机 SSH。当前契约见 [输出读取](../../../current/jobs/index.md#输出读取)。
