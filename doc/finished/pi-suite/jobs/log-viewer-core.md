# 日志实时查看与历史分页基础阶段

目标：通过共享详情框架查看运行中和已结束 job 的各通道日志，保持有界读取与稳定阅读位置。

## 完成项

- [x] DetailsView 统一静态详情与动态日志操作栏，ScrollView 支持正文刷新、底部跟随及阅读位置保留。
- [x] 日志初始显示末尾最多 64 KiB，支持前后字节窗口与返回最新；使用安全字面量文本，正文中的 Markdown 和代码围栏保持原样。
- [x] 运行中仅在底部且未输入搜索时刷新正文；暂停阅读保留正文和搜索，结算后补读最终输出，关闭视图不停止 job。
- [x] 共享字节分页保留实时写入中未完成的 UTF-8 字符，后续读取返回完整字符。
- [x] Linux 真实进程核对实时与历史窗口、中文边界、40/60/120 列布局、列表插入后的游标与范围筛选。

适用范围：Pi 1.5.0、Linux Node.js 24；Windows 日志查看、完整选择与确认停止流程、停止竞争和 agents 级联接入仍由 [历史控制专项](../../../todo/pi-suite/index.md) 管理。
