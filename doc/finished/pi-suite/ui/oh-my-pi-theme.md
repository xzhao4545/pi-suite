# Oh My Pi 参考主题

## 已完成

- 新增 `oh-my-pi` 深色主题，参考 Oh My Pi 固定提交的 Titanium 配色，适配 Pi 1.5.0 原生主题 schema。
- 包声明通过 `pi.themes` 发布主题，覆盖全部 56 个颜色角色，包括列表选中、全屏滚动条、搜索、消息、工具、Markdown、diff、语法及思考强度。
- 增强灰色细边框，使用低亮度选中和状态背景，保持正文与次要文字在所有面板上的对比度。
- 主题选择、包开发预览、独立安装、热重载及终端/Starship 配色边界沉淀于 [当前主题文档](../../../current/ui/themes.md)。来源固定提交与完整 MIT 许可证登记于 third-party。

## 验证范围

Pi 1.5.0 严格 schema 验证通过；truecolor 与 256 色模式下全部角色解析通过，原生用户消息和 Markdown 在 40/80/120 列渲染无宽度溢出。Pi 包资源发现加载主题一次且无诊断。sRGB 正文及次要文字在七类面板上的最低对比度为 4.80:1。

验证未覆盖不同终端的实际视觉观感；终端默认前景、背景及第三方状态栏独立配色不由主题 JSON 统一控制。
