# 导航焦点、Dock 只读任务与问题标题

## 范围

本专项实施新增交互细节，并归档已完成的浏览配色、内联输入/跟随、child 会话目录计划。执行界面其他待办继续保留，本轮不提前实施工具外框、Jobs 同屏终端或 Subagents 底部信息栏。

## 正式需求

1. `/jobs`、`/tasks`、`/subagents` 的共享浏览器在 Tab 切换列表/详情时有明确的焦点标记；活动区域标题和选中行适度强调，非活动区域仍可阅读，不用整面板灰化破坏状态颜色。过滤、搜索、消息和鼠标焦点一致。
2. 空主输入框按左进入 Dock 后，Tasks 同 Agents/Jobs 一样可以逐行选择；Enter 只打开只读详情，不提供任务进度修改、删除等操作。任务组与子任务均可阅读。
3. Dock 激活时 `[` / `]` 快速切换可选择分区，顺序保持 Tasks → Agents → Jobs；空分区和数量摘要不参与。普通主编辑器或文本输入态不拦截这两个字符。
4. 折叠提示按隐藏行的真实位置显示：前方隐藏放上方，后方隐藏放下方，分散隐藏放对应间隙；到达最后一项后不再在下方显示隐藏项。组与子项分别计数，单项可用同一行直接展示。小预算保留真实选择身份并用紧凑上下数量提示，不能打开不可见对象。
5. Suite 生成的 UI 提示统一英文，包括 Tasks 完成尾线/工具反馈、Ask 展开/全文等提示。用户提供的任务标题、问题、程序输出和密码提示识别不翻译或破坏。
6. Types 配置模型支持与 `/model` 一样便捷的输入筛选，完整模型身份与显示标签分离，No override 和 thinking 选择保持原契约。
7. Ask 页签显示简短问题标题而非 Q1/Q2；完整问题仍在正文，Review 保留。标题来源、安全清理、窄屏和鼠标命中区域统一处理，不额外调用模型生成标题。

## 验收

- 宽/窄屏中 Tab、Esc、过滤、搜索、消息输入和鼠标切换均可看出活动区域；保留当前选择、查询、阅读位置和状态颜色。
- Dock Tasks 的组/子项可选择与只读查看；切换三分区及返回无状态修改，非空编辑器、补全、Ask 和详情仍拥有自己的按键。
- 单层、多组任务和各预算下遍历首/中/尾项、刷新删除与重排，隐藏位置/数量正确，所选对象可见且宽高不越界。
- 模型筛选不改变值或配置来源，无结果与清空/取消处理清楚。
- Ask 两题、多题、长/中文标题、窄屏和页签点击正确；题目全文与回答状态不因切页改变。
- 三个已完成计划移入 finished 并保留正文，索引与相对链接修正；同步当前操作说明，仅保留相关风险测试。

## 实现与验证结论

- BrowserView 和 browser-chrome 统一焦点角色，原生 Input、SelectList 和 ScrollView 保留输入、选择与阅读状态；主会话 footer 未修改。
- Dock 的分区顺序与预算优先级分离，Tasks 使用共享字面量详情模式，折叠窗口保留真实对象和方向数量。
- 模型选择使用原生模糊筛选与宿主 keybindings；Ask 批量题目新增可选 title，短标题与可点击区域共用宽度预算。
- Typecheck 通过；全量 190 项测试全部通过，约 45 秒。相关 SDK/组件契约覆盖 40/60/120 列、微小 Dock 预算、单层与父子列表、只读数据快照、鼠标/搜索/输入焦点、模型筛选及 Ask Unicode 页签。
- 本专项未新增实际 Pi CLI 的主观视觉验收；不同终端与第三方主题的最终观感仍需用户确认。其他执行界面待办见 [执行界面专项](../../../todo/execution-ui/index.md)。
