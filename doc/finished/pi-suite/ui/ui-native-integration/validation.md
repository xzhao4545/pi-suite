## 自动检查范围

优先更新现有检查，不为每个小细节新增一个固化测试。针对跨模块风险合并验证：

1. **公共工具壳与回放契约**：沿用 `tests/runtime/tool-render.test.ts`、`tool-history.test.ts`，调整 self/横线断言，验证部分结果接替、错误全文、历史与 child renderer。
2. **任务恢复与 Dock 布局契约**：沿用 `tests/tasks/ui.test.ts` 与 `tests/runtime/coordinator.test.ts`，覆盖恢复基线与真实完成反馈；用 ANSI 去除后的可见列核查选中不移动，并复核公共选中样式消费者。
3. **原生阅读布局与事件链**：沿用 `tests/runtime/transcript.test.ts`、`tests/ui/viewer.test.ts`、`tests/agents/viewer.test.ts`，验证实际布局中的滚动节点、偏移后点击、工具高度变化、首次到底部和搜索/暂停保持。
4. **共享消费者与生命周期**：复用已有 Jobs 日志/查看器、Ask、workflow、阅读框架检查，核查正文预算、逐流窗口、原生 Editor、返回焦点与关闭释放；只为明确缺失的跨模块风险补检查。

不得只直接调用 ToolExecutionComponent.handleMouse 并据此宣布 Subagent 点击通过；必须经过 DetailsView、滚动布局和 Transcript。也不得只断言 scrollbar 配置字符串就宣布滚动条通过，需验证实际宿主布局与可见绘制。

新增测试条目保持不超过六项功能的三倍，不为宽度、状态或每种工具做重复笛卡尔组合。日常定向验证控制在 5 分钟内，全量控制在 10 分钟内；每轮先检查相关模块，稳定后再做必要全量检查。

## 实际 TUI 验收契约

- 使用当前支持的 Pi 版本及真实扩展登记入口，不仅使用纯字符串 mock。
- 代表尺寸采用 40×24、80×30、120×40，并在阅读期间进行一次动态缩放；补充紧凑 Dock 单行预算，不做无目的的全部尺寸组合。
- 同主题对照原生工具外壳，核查正常/错误背景及工具内代码高亮；主题切换后颜色更新。
- 实际打开保存有 done 任务的会话，观察首次可见帧及 5 秒后状态；随后完成未完成组验证实时反馈。
- 实际进入 Dock，连续选择组与子任务，观察左侧对齐、状态和长标题/后缀，不只比对整行字符串。
- 分别打开活动与结束 Subagent；向上阅读、搜索、点击工具、返回子页、收到新输出后按 End，核查底部信息栏。
- 在长历史非零偏移处点击工具，展开后再点击其他工具；确认命中坐标随着内容变化和 resize 更新。
- 核查所选原生 scrollbar 策略的显示、隐藏或预留列，以及正文不足一页时行为；若使用拖动/轨道点击，验证与原生偏移一致。
- fullscreen 验收标准鼠标交互；inline/普通模式按宿主能力验证键盘路径、overlay 高度与恢复焦点，不承诺终端未提供的点击/滚动条能力。
- 核查未处理的文本拖选及 OSC 8 链接不被工具点击拦截；终端复制通道保持现有规则。
- 关闭与重新打开查看器后，无遗留订阅、时钟、自动隐藏计时器或 detached 子组件焦点；不停止 child/job、不切换主会话归属。

只记录通过结论、适用平台/模式及未通过项，不在长期文档保存临时产物路径、会话调度流水账或截图归档清单。未验证的平台/模式不得借用既有专项结论标记为通过。

## 验收结论与边界

- **最终检查**：离线 frozen-lockfile 安装与 `pnpm typecheck` 通过；最新 `pnpm test` 全量 **220/220 通过，约 1 分钟**。以下结论限于真实 TUI/SDK、组件及受控环境证据。
- **UI-1–UI-6**：Pi 原生工具外壳及调用/结果接替、完整错误、任务恢复基线与真实完成反馈、等宽选中、首开末尾定位、单项工具点击和原生滚动条均已验证。
- **原生布局与鼠标链**：真实 `TuiAltScreen` 的 SGR 输入经 overlay → Details → Scroll → Transcript，在非零偏移处展开多个工具及工具高度变化后命中正确；scrollbar 已实际绘制，hover、拖动、轨道点击和 auto-hide 均有证据，不只是配置断言。40×24、80×30、120×40 及动态 resize、关闭后焦点释放均通过。
- **SDK 阅读状态**：首开活动、completed、failed、stopped、readonly run，以及从 Details 返回后的阅读位置、暂停与搜索保持已覆盖。failed/stopped 使用终态夹具，证明对应终态的阅读行为，不是实体失败或停止流程验收。
- **共享消费者**：Jobs 外层原生 scrollbox、stdout/stderr 逐流窗口与暂停/补读、PTY 屏幕及导航边界、Ask History、workflow 共享阅读消费者均通过；PTY 继续使用二维终端框架，不改为文本阅读器。
- **发布入口补验**：包的实际 Node bin 与导出 RPC 入口共用 unbundled patched 模块；真实 Linux CLI 经 PTY/xterm，在 fullscreen 与 regular 模式打开 Subagents、Jobs、Tasks、返回和 resize，并验证 native host/extension 类身份、Subagent 工具点击及 CLI prepared-fork。直接 SDK/TUI 测试不替代发布入口验证，预构建 bundle 的静态模块不作为该补丁组的入口。
- **覆盖边界**：使用真实原生 TUI/SDK 路径不等于实体人工终端验收；本专项未进行实体人工终端或 Windows 验收，不据此声明所有终端、平台或未提供的鼠标能力已验证。无外网账号凭据，不作真实账号权限、解密或中转粘性证明。
