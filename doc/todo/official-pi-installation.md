# 官方 Pi 干净消费者安装验收

## 状态与权限

用户明确要求本轮先不测试安装。本项保留为后续待办，不将仓库 SDK 或实际官方 CLI/RPC 的通过结果表述为消费者安装通过，也不执行 npm publish。

包保持 `private:true`，三个 Pi peer 精确限定为 `1.5.0`；分发方向为 Git/本地包。当前代码及官方运行入口的验证范围见 [运行时边界](../current/runtime/index.md#宿主加载边界) 和 [模型私有桥接](../current/agents/models.md#模型运行时桥接)。

## 验收范围

- 在独立消费者目录安装插件及官方 Pi 1.5.0，不能复用仓库已安装模块或定制启动入口。
- 通过官方 `pi install` 与包 manifest 发现扩展、skills、themes；不靠显式仓库 `-e` 路径代替包安装。
- 检查官方 bin/RPC 导出、命令来源、公开 TUI 组件身份，以及 child 的父 runtime 桥接。
- 验证普通工具请求、任务持久 fork、查看器返回与退出；不扩大为外网账号认证、真实解密或人工终端证明。
- 复核包内容没有宿主 patch/API aliases，不要求用户修改 shell 或全局 Pi 安装。

安装环境需明确包管理器及可用缓存。若离线缓存不足，不自动联网、改写全局缓存格式或换用私有安装入口；执行前询问允许的网络和缓存变更范围。使用已验证的锁文件进行离线安装时，应明确它证明独立安装/加载，不证明重新解析所有 registry 元数据。
