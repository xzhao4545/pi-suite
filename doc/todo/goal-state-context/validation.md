# 验证与维护

[返回专项](index.md)

## 验收原则

先做不收费的真实 SDK/公开协议、Store 和最终请求结构核验，再按需进行最小实际缓存对照。新增回归仅覆盖跨存储、绑定和宿主调度的高耦合风险，复用现有 Goal/Notifications/Tasks 检查；不要为固定文案、字段排列或单个小修补新增永久测试。

日常验证不超过 5 分钟，全量不超过 10 分钟；不反复全量构建，不启动额外 agent 代替确定性检查。

## 单一状态与原子更新

必须验证：

- 多次计量、编辑、暂停/恢复和等待后，磁盘只有该会话一份当前状态，不产生状态版本、完整快照、delta 日志或备份集合。
- 会话 JSONL 不再追加 `pi-suite:goal` 或新计量状态条目；新的恢复回执不携带恢复前完整状态。
- clear 留下当前空状态，旧 JSONL 的目标不能复活；替换覆盖同一文件，计量不串入新目标。
- 原子保存、取消、损坏文件和写入失败保持公共 Store 契约；失败可见，不能静默使用旧历史或反馈未提交成功。
- 锁内检查拒绝过期写入，异步结算不能覆盖较新的 pause/clear/edit/resume；同一目标允许计量的迟到响应不得恢复执行权。
- 无变化保存不重复写入；UI 时钟不写文件、不扫描历史、不调用模型；每次实际更新的持久记录大小取决于当前 Goal，而非运行响应数。

## 会话、分支与恢复

同一会话在不同历史叶子间切换时，当前 Goal 的 ID、revision、进度、用量、预算及手动暂停许可保持，不读取该叶子的旧快照重建状态。切换解除旧 Binding、在途工具和等待资源；新绑定只从当前 Store 获得合法许可。

验证 reload、普通 resume、冷启动、退出、new/fork 与无持久 SDK 场景的作用域。new/fork 不从复制的历史获得 Goal；不同主会话隔离；冷启动未完成目标仍要求显式恢复。一次性导入取全会话追加顺序最新状态，存在新文件或当前空状态时不再导入；旧 JSONL 内容与引用保持原样。

## 上下文与调度

围绕完整流程做定向序列验证，而不是分别固化每个 JSON 字段：

1. 创建目标后自然连续工具工作：目标说明只交付一次，统计变化不改变已有模型消息；宿主未停止时不发送短续跑。
2. 自然结束且 Goal 未完成：最终可动作边界只安排一次继续；已有工具、重试、压缩、扩展继续或待处理消息优先。
3. 等待与混合通知：真实结果/提问身份、交付回调、指定等待准入和自动轮计数不变，不增加独立 Goal 正文或模型轮询。
4. pause、取消、完成、修改、历史切换与恢复：必要时只追加当前语义，过时说明不授予工具权限，未交付的控制请求被撤销。
5. Tasks reminder 与强制系统提示共同存在：保留提示与工具声明，没有临时尾部消息反复出现/消失，也不每请求重建系统 head。
6. 压缩后从当前 Store 重建必要目标说明，下一请求复用，不从摘要或旧 Goal 条目恢复权威状态。

保留执行/仅结案审计、完成幂等、预算（含缓存 token）、skip/timeout 非授权、真实阻塞和连续五个自动轮无工具/相同活动的既有风险验收。针对 `agent_end` 到最终边界期间的恢复和旧控制代次竞态复用现有检查。

## 缓存验收与费用边界

不以 UI 隐藏、缓存键相同、离线转换或无 Goal 的子代理命中代替主会话请求验证。先检查最终可观察 payload 的系统提示、工具、缓存键、input 项及相邻请求共同前缀；日志仅保留必要结构/哈希和用量，不保存认证、密钥、项目正文或密文。

优化实现必须消除已验证的“上一请求尾部合同被移除”序列。实际收费验证仅在明确授权和预设请求/用量上限后进行，优先使用小型合成历史，不重放大型真实项目上下文；不自动重试、不自动切换上游，核对每笔实际凭据一致性，错误或证据足够即停止。

对照以重复请求和优化后的正常追加请求为主，核对缓存读取是否复用前次稳定历史；不要求由 Goal 触发一次真实跨资源错误。压缩、资源切换和 TTL 等正当失效与 Goal 主动改写历史分别报告。不得用 token 数虚构货币费用或把配置零价格当成实际零费用。

必要验收只记录结论、适用范围和未通过项，不长期保存临时脚本、原始收费请求、会话调度流水或本机产物路径。生产缓存算法/内部模型不可观测的部分不能写成已证事实。

## 改动范围与文档同步

预计修改范围：

- `src/goal/`：Store/schema、Manager 的持久事务和归属、上下文交付、命令与回执、等待/生命周期集成。
- `src/runtime/json-store.ts`：仅在现有能力不足时统一扩展缺失文件、异步修改或观察边界，不改变其他 Store 的契约。
- `src/runtime/notifications.ts`、`src/runtime/suite.ts`：公共交付来源、自动续跑准入、绑定和压缩重建协调。
- `src/tasks/index.ts`：将 reminder 接入公共稳定消息路径，保留任务框架语义。
- 现有 `tests/goal/`、runtime/Tasks 相关检查：调整状态源与高耦合序列，不新增并行测试框架。

实现完成后局部更新 `doc/current/goal/`、`doc/current/runtime/index.md`、相关工具/存储说明、Tasks 操作说明与验证范围。同步新的分支含义、单一状态路径、恢复回执操作、new/fork 和迁移规则；新设计实施前不得提前写成 current 已实现事实。

专项全部完成后将本目录移动到 `doc/finished/`，更新 todo/finished 索引并沉淀 current；归档后不再修改。提交仅包含本专项实际改动，不夹带其他未提交文件。
