### 4.3 选项说明、长列表和滚动

上游 options 已支持 `description?: string`，每个选项可设置额外说明。问题级 context 是整个问题的背景，选项级 description 是该选项的解释，二者分别保留。

上游目前的显示行为：

- 单选有模糊搜索，搜索包含标题和说明；上下键移动选项，可见窗口跟随当前项。
- 多选也能上下移动并调整可见窗口，但没有与单选等同的搜索输入实现。
- 窄屏/列表布局将说明换行放在标题下；宽屏单选可以在右侧预览选项说明。
- 单项说明超出行数预算时，窄屏列表和宽屏详情预览均可能只显示开头。详情预览使用顶部切片，没有独立的说明滚动偏移。
- 问题及 context、批量最终确认页有部分翻页/滚动处理；这些能力不能当成任意选项说明已经可以完整滚动阅读。

自定义包需要实现完整、相互独立的列表和说明视口：

1. 列表固定占用分配到的高度，每项以短标题为主；当前项可显示 1–2 行说明摘要。过长标题按可见宽度截断，完整标题在详情中可读。
2. 大量选项通过上下移动、翻页和搜索浏览，显示当前位置/总数与上下溢出提示，不在常驻区域展开整张列表。
3. 单选和多选都提供搜索；多选筛选仅改变可见项，全局勾选集合按选项 ID 保存，并显示已选数量。
4. 宽屏显示“列表 + 可滚动详情”；窄屏提供“查看说明”入口，进入完整说明视图。详情支持自动换行、Markdown、按行/按页滚动和到顶部/底部，保留全部原始文本。
5. 列表、详情、历史和回答输入各自维护焦点与滚动位置，翻页键只作用于当前焦点。鼠标滚轮按终端支持情况增强，同时始终提供键盘与可选中的上一页/下一页/返回入口，适配手机 SSH。
6. 关闭详情、切换题目或缩放终端后恢复原选择和输入；查看说明不提交答案，也不重置超时。
7. 展开详情不把所有长说明堆进 dock。默认询问仍控制高度；需要大空间时使用独立详情/历史回答视图，返回后恢复原布局。

验收需覆盖：单项说明长于一屏、几十个长选项、单选/多选搜索、预选项被过滤隐藏后仍保留、手动取消默认项、手机窄屏缩放和阅读返回。选项数据不得因界面截断而丢失。
