# 用户询问待办

目标：在保留聊天查阅空间的前提下，支持超时、批量、多选、推荐、默认答案和长内容查阅。

当前状态：待实施；当前扩展入口尚未注册 ask_user。

影响范围：ask 工具、ui 的布局和焦点、等待期间的运行时通知。

约束：推荐、默认值、焦点和提交分开；查阅内容不丢失草稿，不重置超时；所有本包面板共用高度预算。
