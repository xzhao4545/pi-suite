# 目标管理

goal 模块为每个主会话保存一个持久目标。目标处于 active 时，模型在每轮结束后自动继续下一轮，直到它用证据完成目标、报告外部阻塞，或目标被暂停。同一会话的所有树分支共用这个目标。

- 开关：`modules.goal` 决定是否加载。
- 显示：`goal.display` 为 `status`（默认，底部状态行）、`dock` 或 `hidden`。
- 源码：`src/goal/`；状态发布、会话绑定和继续请求使用公共 `src/runtime/` 与 `src/ui/`。
