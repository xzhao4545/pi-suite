# Oh My Pi 参考主题

本包通过 `package.json` 的 `pi.themes` 发布 `themes/oh-my-pi.json`，主题名为 `oh-my-pi`，适用于深色终端。配色参考 Oh My Pi 的 Titanium，使用蓝灰面板、电蓝强调色、浅灰文字与绿／橙／红状态色；源码与许可证见 [上游来源](../../../third-party/UPSTREAM.md)。

## 加载与切换

主题 JSON 使用 Pi 原生主题协议，可单独用于原版 Pi。当前完整包同时加载 Suite 扩展，其宿主补丁及加载条件见 [运行时边界](../runtime/index.md#宿主加载边界)；完整包不能按单独主题的兼容性推定可在官方 Pi 1.5.0 中加载。

在满足当前扩展加载条件的开发宿主中，将本包作为 Pi package 安装后执行 `/reload`，再打开 `/settings` → **Theme** → `oh-my-pi`。选择由 Pi 保存到设置文件，不依赖 Suite 业务模块是否启用。

仅使用 `pi -e ./src/index.ts` 会加载扩展文件，不会加载包主题。开发时使用整个包：

```sh
pnpm exec pi -e . --use-theme oh-my-pi
```

该命令只为本次启动选择主题。也可以将 JSON 单独安装到 `~/.pi/agent/themes/oh-my-pi.json`，再通过 `/settings` 选择；同名主题只保留一个加载来源，避免与已安装的本包主题发生冲突。

包主题编辑后执行 `/reload`；放在用户主题目录的活动主题支持 Pi 原生热重载。自定义颜色集中在 `vars`，`colors` 只映射 Pi 原生语义角色，不使用额外的主题协议或渲染器。

## 配色与边界

- 标题、选中标记及高亮边框使用电蓝色；普通边框与内部细线使用不同亮度的蓝灰色。
- 选中行使用深蓝背景，搜索匹配使用暗金背景；正文和次要文字在这些背景上保持至少 4.5:1 的对比度。
- 用户消息与待执行工具使用深灰面板，工具成功／失败分别使用低饱和度的绿／红面板；结果状态仍通过原生 success/error 角色表达。
- Markdown、语法高亮、diff、思考强度边框、Bash 模式以及全屏滚动条使用完整的 Pi 主题角色。HTML 导出使用同一套深色面板。
- 主题只控制 Pi 暴露的配色角色，不控制布局、图标、圆角边框字符、字体或终端默认背景；希望未着色区域也匹配 Titanium 时，可将终端背景设为 `#151820`、前景设为 `#e8ecf4`。
- Pi 助手正文中的默认文字由终端前景决定；显式 `text` 角色作用于编辑器及扩展等主动调用该角色的表面，不会给全部 Markdown 正文统一覆色。
- Suite 的 Dock、询问、列表与详情复用宿主主题角色；第三方 Starship 的独立 TOML 配色由其自身配置管理，不由本主题覆盖。
