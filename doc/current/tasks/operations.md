# 任务操作与显示

`/tasks [group ID]` 通过共享阅读 overlay 打开浏览器，标题为 `Tasks ▸ List`。默认 State 为 All，包含已完成组与子任务；指定组 ID 查看该组，State 可切换为 Unfinished、Running、Blocked、Completed。非 TUI 模式通过通知展示对应文本。

| 详情操作 | 行为 |
| --- | --- |
| / 后输入文字 | 进入过滤，筛选当前范围的 ID、标题、说明、阻塞原因与状态；直接输入字符不筛选 |
| ↑/↓、PageUp/PageDown、鼠标滚轮 | 选择列表项；详情焦点下滚动正文 |
| Tab | 列表进入详情，再次 Tab 或 Esc 返回列表；过滤内 Tab/Enter 保留查询并回到列表 |
| g / s | 一次循环并应用 Group / State，不进入 Tab 焦点环 |
| /、Enter、n/N | 详情内搜索，定位下一/上一匹配 |
| Enter | 选择任务并返回，Dock 选中其所属组 |
| Esc | 退出详情搜索/焦点，清空筛选或关闭浏览器 |

默认焦点在列表；活动区域标题使用 `▸`、accent、粗体及 accent 横线，非活动标题为 muted；离开列表时移除选中背景，任务状态色与完成删除线保持不变。过滤/详情搜索有明确输入焦点与原生光标，鼠标点击/滚轮更新所在区域焦点，悬停不夺焦点。状态行显示 List、组/状态筛选、匹配数/范围总数、选中标题与任务 ID；窄屏优先保留页名和选中对象。过滤内 Esc 清空并退出，详情搜索内 Esc 仅退出搜索。BrowserView 声明 capturesViewportInput，使 fullscreen 的翻页键作用于当前列表或详情而非主会话。

宽屏左侧显示 `图标 ID 标题` 与组进度，右侧显示说明、依赖和执行引用，窄屏改为上下布局。浏览器订阅同一 TaskStore，提交后更新正文，选中任务 ID、各项搜索和阅读位置保持稳定；删除所选任务时定位相邻项。任务标题和说明显示为安全字面量文本。浏览期间收起 Dock 并暂缓结算通知，关闭后恢复。

主会话编辑器为空时按 ← 进入 Dock；Tasks 与 Agents、Jobs 均参与 ↑↓ 选择，`[`/`]` 循环切换可选分区。Tasks 使用 `Enter view` 提示查看，标题不重复只读标签；Enter 打开组或子任务的只读详情，支持滚动、搜索与返回，不提供修改操作；查看不改变焦点组、任务状态、依赖或执行引用。退出查看器后再次按 ← 可回到上次对象；选中只增加背景与粗体，保留层级前缀的原空格数、文字起始列和后缀预算，不切换字号。主编辑器非空或其他组件占用焦点时不接管按键。框架生成的提示使用英文，用户提交的标题、说明和阻塞理由保持原文。

## 常驻摘要

tasks 向共享 Dock 提交 Tasks 分区，标题显示全部子任务完成数/总数；空闲 Dock 与编辑器、footer 共用半屏预算，未处于活动选择且 Tasks 可见时优先展开 Tasks，Agents/Jobs 保留预算允许的必要摘要；退出选择即恢复默认策略，保留上次对象身份不会固定展开其他分区。Tasks 为空或完成反馈结束时仍按既有规则隐藏，活动选择始终优先保证真实选中分区与对象可见。询问打开时整个 Dock 让位，关闭后恢复。行首使用 ☐/⟳/⚠/☑ 表示待办、进行中、阻塞、完成，随后为 ID 与标题，阻塞项标题后附加 `(Blocked)`；组右侧显示该组完成数/总数，长标题优先截断。待办使用与 Tasks 标题一致的 accent（默认紫色）、进行中使用 success（默认绿色）、阻塞使用 warning（默认黄色）、完成使用 dim（灰色）与删除线，颜色跟随当前 Pi 主题；Dock、命令列表与工具输出共用 presentation.taskTone/taskRow/taskStyle；Dock 负责树形层级，标题、竖线与尾线计入预算。竖线与尾线按全部子任务完成比例沿阅读顺序染 accent，未完成部分为 borderMuted。

焦点组依次取选中组、doing、blocked、最近更新；父级依赖或 blocked 子项提高阻塞优先级，同级以最近变更和稳定 ID 排序。全部可见组的子任务均作为候选，组内始终按任务 ID 顺序显示；预算不足时优先保留焦点组当前子任务、doing/blocked、当前项之后的待办、最近一个已完成项及其余对象。当前子任务取最近 updatedAt 的 doing，其次首个 blocked、首个 todo。↑↓ 可到达其他组的子任务与列表末项；折叠的子项与组分别计数，`↑/↓/↕ … N more items/groups` 放在真实隐藏片段位置，只缺一项且同样占一行时直接显示该项。空闲预算为 1–3 行时使用 `Tasks 完成数/总数 · 当前子任务` 单行摘要，不画树形线；激活选择优先保留真实选中对象，放不下方向提示时标题显示 `↑N ↓N`。宽度不足 40 列省略树形线，保留标题。

部分组完成时，数量并入尾线 `└───── ☑ N completed groups`。冷加载、reload/resume/fork 与树重绑的初始快照和订阅刷新只建立恢复基线，已有 done 项不触发完成反馈。绑定就绪后的真实完成反馈保留 5 秒；全部组完成且反馈结束后隐藏整个 tasks 分区，任务数据仍可通过 `/tasks` 查看。回调按 Store 与 Binding 身份隔离，离开会话后的通知或计时器不影响新清单。当前查看的组可通过 `/tasks` 的组 ID 选择并提高显示优先级，其他任务最近更新不会改变所选稳定 ID。


task_edit 调用中显示 `Updating tasks`，结果折叠为一行：单回执为任务与动作，多回执按动作分别统计组与子项，并附依赖变化和警告数；展开显示全部回执、派生变化、字段、组进度与警告。task_list 折叠为筛选、组/子数量、状态计数与下一页摘要，展开显示两级任务行；task_get 折叠为任务行，展开显示完整详情。鼠标左键点击结果切换该项，Pi 的 app.tools.expand（默认 Ctrl+O）切换全部；工具失败正文始终完整可见。显示采用 Pi 原生 renderer，真实工具结果和会话记录继续保留。

## child 任务范围

child 的 task_list 与默认 scope:local 的 task_get/task_edit 操作自己的私有清单，私有项不显示在主会话 Dock；可在 `/subagents` Transcript 查看工具调用与结果。agent_start(taskId) 分配的父级任务用 `task_get({"scope":"assigned","id":"1.2"})` 读取，用 `task_edit({"scope":"assigned","op":"done","id":"1.2"})` 更新，仅允许 start/done/block/unblock。assigned 批次的所有操作须作用于同一分配任务，不接受 CRUD 或其他父级 ID，越权返回 TASK_SCOPE；scope 作用于整批，不在 changes 内设置。同名的私有 `1.2` 仍由省略 scope 或 scope:local 操作，编号不会隐式切换清单。

## 提醒

配置 tasks.reminders 默认 true，用户或项目的 pi-suite.json 可设置 false。未使用任务工具的间隔达到 4 轮时，在下一次模型请求加入一次任务提醒；存在 doing 子任务时缩短为 2 轮。task_list/task_get/task_edit 使用重置间隔并允许下一次提醒。

提醒最多回显 10 个未完成清单项，仅进入当次 context，不持久保存到会话，也不修改工具结果。child 提醒读取其私有清单，并说明分配任务 ID 与 scope:assigned 的受限入口，不回显父级清单。提醒不会修改任务、停止执行或自动完成 goal。
