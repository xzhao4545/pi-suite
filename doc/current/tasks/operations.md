# 任务操作与显示

`/tasks [all] [group ID]` 打开共享浏览器。默认显示未完成组与子任务；all 包含已完成项，指定组 ID 查看该组。非 TUI 模式通过通知展示对应文本。

| 详情操作 | 行为 |
| --- | --- |
| 输入文字 | 筛选当前范围的 ID、标题、说明、阻塞原因与状态 |
| ↑/↓、PageUp/PageDown、鼠标滚轮 | 选择列表项；详情焦点下滚动正文 |
| Tab / Shift+Tab | 切换 Group、State、输入、列表、详情焦点 |
| ←/→、Enter | 顶部控件选择并应用组或状态，完成项只有 State 中一个入口 |
| /、Enter、n/N | 详情内搜索，定位下一/上一匹配 |
| Enter | 选择任务并返回，Dock 选中其所属组 |
| Esc | 退出详情搜索/焦点，清空筛选或关闭浏览器 |

宽屏左侧显示 `#ID 标题` 与状态/组进度，右侧显示说明、依赖和执行引用，窄屏改为上下布局。浏览器订阅同一 TaskStore，提交后更新正文，选中任务 ID、各项搜索和阅读位置保持稳定；删除所选任务时定位相邻项。任务标题和说明显示为安全字面量文本。浏览期间收起 Dock 并暂缓结算通知，关闭后恢复。

## 常驻摘要

tasks 只提交行给共享 Dock，遵守 ask、goal、jobs、agents 共用的高度预算。左侧固定为 `#ID 标题`，子任务轻量缩进；右侧用 ⟳/⚠/✓/· 表示进行中、阻塞、完成、待办，组另带完成数/总数，长标题优先截断。主题强调/警告/成功/弱化色与完成删除线共用 presentation。Dock 按重要性为执行子项连带保留父级行，再分配其余摘要；父子相邻，隐藏数量遵守共享高度预算。打开询问时改为单条压缩摘要，完成比例、⟳ 和 ⚠ 数量按实际子任务统计，完成任务不计入 blocked。

显示优先级为选中组、当前执行、阻塞待处理组、完成反馈、普通待处理组；同类按最近变更稳定排序。父级自身有未完成依赖或包含 blocked 子任务时提高该组优先级。已完成子任务和父级反馈保留 5 秒后收起，完成组汇总为 completed N groups；折叠与收起不删除任务。当前查看的组可通过 /tasks 的组 ID 选择并显示 `›` 标记，其他任务最近更新不会改变所选稳定 ID。

task_edit 调用中显示简短“正在更新任务”，完成后只显示实际开始/完成/阻塞/更新项；展开查看变更字段、组进度与警告。task_list 默认显示有限清单，展开和下一页提示明确；工具失败正文保持可见。显示采用 Pi 原生 renderer，真实工具结果和会话记录继续保留。

## 提醒

配置 tasks.reminders 默认 true，用户或项目的 pi-suite.json 可设置 false。未使用任务工具的间隔达到 4 轮时，在下一次模型请求加入一次任务提醒；存在 doing 子任务时缩短为 2 轮。task_list/task_get/task_edit 使用重置间隔并允许下一次提醒。

提醒最多回显 10 个未完成清单项，仅进入当次 context，不持久保存到会话，也不修改工具结果。提醒不会修改任务、停止执行或自动完成 goal。
