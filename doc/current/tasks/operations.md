# 任务操作与显示

## /tasks

`/tasks [group ID]` 打开 `Tasks ▸ List`。不传组 ID 时查看所有组；State 默认为 All，包含已完成的组和子任务。传组 ID 时只看该组。非 TUI 模式通过通知输出相同范围的任务详情，不加载交互查看器。TUI 首次打开命令或 Dock 详情时才加载 `viewer.ts`（任务查看器），见 [加载与首次就绪](../runtime/index.md#加载与首次就绪)。

| 按键 | 行为 |
| --- | --- |
| `/` | 列表中打开过滤，匹配 ID、标题、说明、阻塞原因和状态；详情中打开正文搜索。直接输入字符不筛选。 |
| ↑/↓、PageUp/PageDown | 列表中选择任务，详情中滚动。 |
| Tab | 列表与详情之间切换；过滤时保留查询并返回列表，Enter 也可确认过滤。 |
| `g` / `s` | 直接循环 Group / State，不进入 Tab 焦点环。State 依次为 Unfinished、Running、Blocked、Completed、All。 |
| Enter | 在列表选择任务并退出，使其所属组成为 Dock 的焦点候选；搜索中确认查询。 |
| `n` / `N` | 详情中跳到下一处 / 上一处匹配。 |
| Esc | 详情搜索中退出搜索并保留查询；详情中回到列表；过滤输入中或列表有过滤时清除过滤；否则关闭。 |

默认焦点在列表。宽屏左侧是`图标 ID 标题`和组进度，右侧是说明、依赖和执行引用；窄屏上下排列。焦点标题用 `▸`、粗体和 accent 横线，非焦点标题为 muted。详情获焦时移除列表选中背景，保留状态颜色和删除线。状态行显示页名、组和状态筛选、匹配数/范围总数、选中标题和 ID；窄屏优先保留页名与选中对象。框架提示使用英文；用户提交的标题、说明和阻塞原因保持原文，以字面量显示。翻页键由查看器接收，不滚动主会话，阅读窗口不显示滚动条；输入焦点、原生光标和阅读窗口见 [BrowserView](../ui/index.md#browserview)，鼠标限制见 [原生阅读与鼠标](../ui/terminal.md#原生阅读与鼠标)。

查看器订阅当前清单，同一代次下保留选中任务、搜索和阅读位置；所选任务删除时移到相邻项。清单代次变化时重置组筛选，选择键中的代次防止旧 ID 指向新任务。浏览期间收起 Dock 并暂缓通知，关闭后恢复。

### Dock 查看

空编辑器按 ← 进入 Dock，↑/↓ 选择行，`[`/`]` 循环切换分区，Enter（`Enter view`）打开所选组或子任务的只读详情。详情可滚动、搜索和返回，不编辑任务，也不改变 `/tasks` 记住的焦点组。退出后再次按 ← 可回到上次仍可选的对象。接管条件和选中样式见 [Dock 键盘进入](../ui/index.md#dock-键盘进入)。

## 常驻摘要

标题显示全部子任务的完成数/总数，组行右侧显示本组完成数/总数，长标题优先截断。`presentation.ts` 提供 Dock、列表和工具显示共用的符号与颜色，颜色取当前 Pi 主题的对应角色：

| 状态 | 标记与颜色 |
| --- | --- |
| `todo` | `☐`，accent（默认紫色） |
| `doing` | `⟳`，success（默认绿色） |
| `blocked` | `⚠`，warning（默认黄色），标题加 `(Blocked)` |
| `done` | `☑`，dim（默认灰色），加删除线 |

`src/tasks/index.ts` 的 `rows(selectedId)` 生成以下候选行。它只展开一个焦点组：

1. 优先取 Dock 当前选中的组或所选子任务的所属组，其次取 `/tasks <组 ID>` 或在 `/tasks` 中按 Enter 选定的组（代次变化时清除）。否则优先取有效状态为 `doing` 的组，再取组或任一子任务为 `blocked` 的组。相同优先级取组及其子任务中最近更新的时间，仍相同则取较小的组 ID。
2. 焦点组显示最近完成的一项（不占未完成项上限）。未完成项通常最多 5 个（`OPEN_CHILD_CAP`）；只有 1 个超出的项时直接显示第 6 项，有 2 个或更多超出项时用 `… N more items` 折叠。需要取舍时优先保留当前子任务、其他 `doing`/`blocked`、当前项之后的待办、其余待办，最后是完成项和折叠行。当前子任务依次取最近更新的 `doing`、ID 最小的 `blocked`、ID 最小的 `todo`。
3. 其他未完成组只显示标题和进度，按组 ID 取最多 4 个（`OTHER_GROUP_CAP`）；剩余数用 `… N more groups` 显示。两种折叠行均不可选。已完成组计入尾线 `☑ N completed groups`；完成反馈期间也可显示组行。
4. 始终按组 ID、组内按子任务 ID 显示。保留优先级不改变显示顺序；预算不足还会裁剪候选行。Tasks 提供自己的折叠行（`gapHints: false`），Dock 不插入方向折叠行。用 Dock 按键选中组或其子任务即展开该组；活动选择优先保留选中对象及其附近的行。

默认分配、半屏预算、选中分区的可见性以及询问占用输入区时的行为见 [Dock](../ui/index.md#dock)。空闲分区只分到 1–3 行，或候选仅一行时，显示 `Tasks 完成数/总数 · 当前子任务` 单行摘要（没有可用子任务时省略后半）；宽度不足 40 列省略树线。标题和尾线占行预算，竖线与尾线按全部子任务的完成比例沿阅读顺序染 accent，余段为 borderMuted。

绑定就绪后，新完成项的反馈保留 5 秒。清单全完成时立即[清空存储](storage.md#清空与引用有效性)，Dock 只保留用于反馈的行，不保存任务历史；反馈行携带源代次，不能打开新代次的同名任务。加载、reload、resume、fork 和树重绑只建立基线，不为已有完成项触发反馈；此时清单若已全部完成，则直接清空，不显示反馈。反馈结束且没有未完成组时隐藏 Tasks。订阅回调与反馈计时器核对当前清单和会话绑定，不能影响后来打开的清单。

## 工具显示

| 工具 | 折叠 | 展开 |
| --- | --- | --- |
| `task_list` | 筛选、组和子项数、状态计数及下一页提示 | 两级任务行、组进度和下一页提示 |
| `task_get` | 任务行及组进度 | `generation` 字段和任务 JSON |
| `task_edit` | 调用中显示 `Updating tasks…`。单条回执显示任务与动作，多条分动作统计组与子项；附依赖变化和警告数 | 实际操作、字段、依赖引起的变化、组进度和警告 |

点击单项、Ctrl+O（默认全局展开键）和失败正文的显示规则见 [工具正文](../ui/index.md#工具正文)。折叠只影响显示，工具结果和会话记录保持完整。

## child 任务范围

| 范围 | 读取 | 写入 |
| --- | --- | --- |
| 本地（省略 `scope` 或用 `scope: "local"`） | `task_list` 和 `task_get` 读 child 私有清单 | `task_edit` 改私有清单。child 启动 job 或嵌套 agent 时，也只从这份清单引用任务。 |
| 分配任务（`scope: "assigned"`） | `task_get` 只读直接父级启动时指定的子任务 | `task_edit` 只允许对它执行 `start`、`done`、`block`、`unblock`。 |

私有项不显示在主会话 Dock；可在 [`/subagents` Transcript](../agents/operations.md#transcript) 查看 child 的调用和结果。主会话和没有分配任务的 child 的工具参数不含 `scope`，工具说明也不附分配信息；`task_list` 始终查本地。两份清单即使都有 `1.2`，也只按 `scope` 和源代次选择，不按 ID 自动切换。

以分配任务 `1.2` 为例，读取用 `task_get({"generation":"<assigned source>","scope":"assigned","id":"1.2"})`，完成用 `task_edit({"generation":"<assigned source>","scope":"assigned","op":"done","id":"1.2"})`。

`scope` 和 `generation` 作用于整批。分配范围不接受 `add`、`update`、`delete`、`clear`、其他 ID 或混用两份清单，违规返回 `TASK_SCOPE`，整批不提交。回执保留分配任务的变化、警告及清空结果，不含父级其他任务的状态变化或组进度；父级订阅仍能收到实际清单更新。

## 提醒

`tasks.reminders` 默认 `true`，可在用户或项目的 `pi-suite.json` 中设为 `false`。清单非空且 4 轮未用任务工具时，模型正常结束该轮（`turn_end` 的结果为 `completed`）后追加一条提醒；有有效 `doing` 子任务时阈值为 2 轮。使用 `task_list`、`task_get` 或 `task_edit` 会重置间隔，并允许下次提醒。

提醒带本地 `generation` 和最多 10 项未完成列表行；有分配任务的 child 还看到其 ID 和 [assigned 入口](#child-任务范围)，不回显父级清单。写入前核对会话绑定及取消信号。提醒作为来源为 `reminder` 的[通知消息](../runtime/index.md#通知消息格式)附加到该轮记录，不改工具结果、不单独发起模型请求；下一次正常请求读到它。任务更新、间隔重置或关闭配置不删除已记录的提醒。提醒本身不修改任务、停止执行或完成 goal，失效代次仍由工具拒绝。
