# 任务操作与显示

`/tasks [all] [group ID]` 打开共享详情。默认显示未完成组与子任务；all 包含已完成项，指定组 ID 查看该组。非 TUI 模式通过通知展示对应文本。

| 详情操作 | 行为 |
| --- | --- |
| ↑/↓、PageUp/PageDown、Home/End、鼠标滚轮 | 滚动当前任务快照 |
| /、Enter、n/N | 输入并提交搜索，定位下一/上一匹配 |
| ←/→、Enter | 选择并执行 Expand / collapse、Show / hide completed 或 Back |
| Esc | 退出搜索或关闭详情 |

详情初始展开直接子任务，操作栏可折叠为父级摘要。打开后使用独立快照，child 更新和完成反馈计时器不会改变阅读中的正文；重新打开取得最新数据。任务标题和说明显示为安全字面量文本。浏览期间收起 Dock 并暂缓结算通知，关闭后恢复。

## 常驻摘要

tasks 只提交行给共享 Dock，遵守 ask、goal、jobs、agents 共用的高度预算。父级摘要固定保留完成数/总数与状态，长标题优先截断。父级默认折叠，有空间时显示 doing 子任务及短暂完成反馈。

显示优先级为当前执行、完成反馈、待处理组；同类按选择与最近变更稳定排序，父级与其可见子任务保持相邻。已完成子任务和父级反馈保留 5 秒后收起，完成组汇总为 completed N groups；折叠与收起不删除任务。当前查看的组可通过 /tasks 的组 ID 选择。

## 提醒

配置 tasks.reminders 默认 true，用户或项目的 pi-suite.json 可设置 false。未使用任务工具的间隔达到 4 轮时，在下一次模型请求加入一次任务提醒；存在 doing 子任务时缩短为 2 轮。task_list/task_edit 使用重置间隔并允许下一次提醒。

提醒最多回显 10 个未完成清单项，仅进入当次 context，不持久保存到会话，也不修改工具结果。提醒不会修改任务、停止执行或自动完成 goal。
